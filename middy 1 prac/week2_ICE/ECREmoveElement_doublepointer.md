Procedure ECRemoveSpace(nums: array of integers, len: integer, val: integer):

1. Initialize a variable 'count' to 0. This will keep track of the position where non-val elements should be moved.

2. Start a loop that iterates through each element in the array, from index 0 to len-1, and for each iteration do the following:
    2.1. If the current element is not equal to 'val':
        2.1.1. Assign the current element to the position indicated by 'count'.
        2.1.2. Increment 'count' by 1.

End of Procedure
